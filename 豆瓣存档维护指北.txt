========================================
二、sort_order.txt 格式详解
========================================

格式：文件夹名 | 权重值 | 备注

【权重规则】
- 权重越小，排序越靠前
- 一级分类：1.0, 2.0, 3.0（整数）
- 二级分类：1.01, 1.02... 2.01, 2.02...（小数点后两位）

【当前配置示例】
姥姥的树存档 | 1.0 | 
新番组存档 | 2.0 | 
真话组存档 | 3.0 | 

姥组吵架整理 | 1.01 | 
史官楼 | 1.02 | 
吵架1 | 1.03 | 
...（完整配置见实际文件）

三、四大维护场景操作步骤
========================================

【场景1：新增帖子文件夹】

步骤1：在对应分类下新建文件夹
   例：在"新番组存档/"下新建"12. 新帖子名称/"

步骤2：放入HTML文件
   例：12. 新帖子名称/1.html, 2.html...

步骤3：修改 sort_order.txt
   在文件末尾添加：
   12. 新帖子名称 | 2.12 | 

步骤4：运行脚本生成新列表
   python generate_sorted_list.py

步骤5：得到新的 list_sorted_xxxx.txt，给AI更新网页

步骤6：推送文件
# 1. 进入项目目录
cd D:\doubanbfgj\douban-group-archive-tool-main\RRZS

# 2. 查看改动了哪些文件
git status

# 3. 添加所有新增和修改的文件
git add .

# 4. 提交，写明这次改了什么
git commit -m "新增月工组存档文件，修复排序规则"

# 5. 推送到 GitHub
git push

----------------------------------------

【场景2：删除帖子文件夹】

步骤1：直接删除目标文件夹
   例：删除"新番组存档/吵架4/"

步骤2：修改 sort_order.txt（二选一）
   方案A：直接删除对应行
   方案B：注释掉（前面加#）：
   # 吵架4 | 1.06 | 已删除

步骤3：运行脚本生成新列表
   python generate_sorted_list.py

----------------------------------------

【场景3：调整显示顺序】

步骤1：修改 sort_order.txt 的权重值
   例：把"建议楼"从第8位提前到第5位

   修改前：
   吵架2 | 1.04 | 
   吵架3 | 1.05 | 
   吵架4 | 1.06 | 
   苹果凌晨出没 | 1.07 | 
   建议楼 | 1.08 |        ← 原来在第8

   修改后：
   吵架2 | 1.04 | 
   建议楼 | 1.05 |        ← 改成1.05
   吵架3 | 1.06 |        ← 改成1.06
   吵架4 | 1.07 |        ← 改成1.07
   苹果凌晨出没 | 1.08 |  ← 改成1.08

步骤2：运行脚本生成新列表
   python generate_sorted_list.py

【注意】权重数字只是相对大小，不需要连续。
        比如可以用 1.01, 1.015, 1.02 来插入中间位置。

----------------------------------------

【场景4：新增一级分类（如新增"小说组"）】

步骤1：在项目根目录新建文件夹
   例：📁 小说组存档/

步骤2：在 sort_order.txt 顶部添加一级分类
   小说组存档 | 4.0 | 

步骤3：在 sort_order.txt 底部添加二级分类
   1. 某小说讨论 | 4.01 | 
   2. 另一小说 | 4.02 | 

步骤4：运行脚本生成新列表
   python generate_sorted_list.py

========================================
四、维护口诀
========================================

新增帖子 = 新建文件夹 + sort_order.txt加一行 + 运行脚本
删除帖子 = 删文件夹 + sort_order.txt删一行（或注释） + 运行脚本
调整顺序 = 改sort_order.txt权重数字 + 运行脚本
改名帖子 = 改文件夹名 + sort_order.txt对应行改名 + 运行脚本

【核心原则】
改完 sort_order.txt 后，一定要运行：
   python generate_sorted_list.py
否则 list_sorted_xxxx.txt 不会更新！

========================================
五、常见问题排查
========================================

Q1：运行脚本后顺序还是乱的？
A1：检查 sort_order.txt 里的文件夹名是否和实际文件夹名完全一致
     （包括空格、标点、全半角）

Q2：新增文件夹后脚本报错？
A2：检查 sort_order.txt 格式是否为：文件夹名 | 数字 | 
     （注意是两个竖线，中间是数字权重）

Q3：只想看HTML文件，但输出里有其他文件？
A3：检查 generate_sorted_list.py 里的 FILTER_EXT = ".html" 是否被注释

Q4：生成的 list_sorted_xxxx.txt 文件名太长？
A4：可以手动重命名，或修改脚本里的 timestamp 格式

【样式参考】
- 整体风格：简洁、类似维基百科/文档站的阅读体验
- 颜色：豆瓣绿色系 (#007722) 为主色调

【特别注意】
- 严禁改变我提供的顺序！txt 文件里的顺序就是最终展示顺序
- 番剧组的 "1. xxx" "2. xxx" 编号要保留并视觉突出
- 所有链接使用相对路径，因为我需要本地打开
